Cómo usarlo:

Asegúrate de tener Python 3.10+ y Google Chrome instalado.

Instala dependencias:
pip install selenium
pip install webdriver-manager
pip install reportlab

Descarga el ChromeDriver compatible con tu versión de Chrome y agrégalo al PATH.

Ejecuta:
python test_biblioteca_virtual.py
